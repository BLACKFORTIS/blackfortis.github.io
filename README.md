# BLACK FORTIS 랜딩 페이지

## 구성

- `index.html`: 포효 영상 인트로, 모바일 반응형 랜딩 화면, 체험 신청 CTA
- `black-fortis-original.png`: BLACK FORTIS 전체 포스터 이미지
- `black-fortis-emblem-roar.mp4`: 사자 포효 인트로 영상

## 실행 방법

세 파일을 같은 폴더에 둔 상태에서 `index.html`을 웹호스팅 서비스에 업로드하면 됩니다. 로컬 확인은 `index.html`을 브라우저로 열어도 되지만, 일부 브라우저의 영상 자동재생 정책 때문에 로컬 서버나 실제 호스팅 환경에서 확인하는 것을 권장합니다.
